✧ 建议的游玩顺序

  1. 正传第 1 部《代号：双子》 — 在 miyeji.cn 上游玩，外传一与之关联紧密。
  2. 外传一 · 星都异闻录 — 档案室推理，认识「温言」与 1,244 这个数字。
  3. 正传第 2 部 — 了解辰天集团与回声计划的全貌。
  4. 外传二 · 回声之网 — 只沿用世界观，不出现前作任何角色，可独立游玩。
⚠ 剧透警告：两份攻略包含全部委托的关键词、线索、分类答案与结局条件。 建议先自行通关一遍，再回来对照。两份攻略页均已内置剧透遮罩，需手动点击才会展开。
⚠ 打开方式：请保持本页与两个游戏文件夹在同一目录下， 并且不要单独移动某个 html 文件。 若浏览器因本地文件策略拒绝加载（页面空白或图片缺失），可在合集根目录执行 python -m http.server 8000 后访问 http://localhost:8000。
